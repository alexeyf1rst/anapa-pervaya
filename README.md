# Первая линия — агентство инвестиционной недвижимости, Анапа

Сайт агентства недвижимости «Первая линия». Доходные апартаменты и апарт-отели: Анапа, Сочи, Архыз, Алтай, Грузия.

## Структура

```
├── index.html           — главная страница
├── politika.html        — политика обработки персональных данных
├── soglasie.html        — согласие на обработку персональных данных
├── spasibo.html         — страница благодарности после заявки
├── netlify.toml         — конфигурация Netlify
├── favicon.ico
└── assets/
    ├── css/style.css    — основные стили
    ├── js/
    │   ├── config.js    — настройки сайта и калькулятора
    │   ├── calc.js      — движок калькулятора «объект против вклада»
    │   └── app.js       — логика: квиз, формы, попапы, аналитика
    ├── fonts/           — шрифты Cormorant Garamond и Jost (woff2)
    ├── brand/           — логотипы и иконки
    ├── team/            — фото команды
    └── objects/         — фото объектов недвижимости
```

## Деплой

Сайт деплоится на Netlify. При пуше в main Netlify автоматически обновляет сайт.

## Калькулятор

Встроенный калькулятор сравнивает доходность объектов недвижимости с банковским вкладом. Параметры расчёта — в `assets/js/config.js`. Данные рынка на 23.09.2026.
